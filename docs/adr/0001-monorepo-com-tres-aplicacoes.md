# Monorepo com tres aplicacoes

O Mercado One adota um monorepo com `backend-api`, `admin-web`, `pdv-desktop` e `infra` para manter a evolucao do MVP coordenada entre API, administrativo e PDV. A decisao reduz atrito de integracao no inicio do produto e deixa contratos, requisitos e documentacao no mesmo espaco de manutencao.
