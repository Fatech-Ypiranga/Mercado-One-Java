# Monorepo com três aplicações

O Mercado One adota um monorepo com `backend-api`, `admin-web`, `pdv-desktop` e `infra` para manter a evolução do MVP coordenada entre API, administrativo e PDV. A decisão reduz atrito de integração no início do produto e deixa contratos, requisitos e documentação no mesmo espaço de manutenção.
