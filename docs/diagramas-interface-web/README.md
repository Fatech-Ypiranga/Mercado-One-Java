# Diagramas da Interface Web do Mercado One

Pasta gerada para a entrega de planejamento da interface web administrativa.

Os arquivos abaixo são HTML autocontidos com SVG inline, criados a partir do material existente no repositório e das rotas atuais do `admin-web`.

- [Arquitetura da Interface Web](01-arquitetura-interface-web.html) - Visão técnica do Admin Web dentro do Mercado One, incluindo API, banco e contexto do PDV offline.
- [Mapa de Navegação do Admin Web](02-mapa-navegacao-admin-web.html) - Estrutura das rotas atuais e agrupamentos de telas entregáveis para o planejamento da interface.
- [Fluxo de Login e Acesso por Perfil](03-fluxo-login-acesso.html) - Sequência esperada entre formulário de login, API, serviço de autenticação e shell administrativo.
- [Relação de Casos de Uso e Telas](04-relacao-casos-uso-telas.html) - Matriz visual das telas web atuais em relação aos principais casos de uso do MVP.
- [Cadastro de Produto e Categoria](05-fluxo-cadastro-produto-categoria.html) - Fluxo de trabalho para manter catálogo no Admin Web antes de disponibilizar produtos ao PDV.
- [Fluxo de Estoque](06-fluxo-estoque.html) - Como a tela de estoque registra entradas, ajustes e impactos operacionais em saldo e relatórios.
- [Fluxo de Dados para Relatórios](07-dataflow-relatorios-operacionais.html) - Fontes de dados e saídas visuais para dashboard, vendas, estoque e acompanhamento offline.
- [Processo de Conflitos Offline](08-processo-conflitos-offline.html) - Caminho da venda offline desde o PDV até a resolução ou o acompanhamento no Admin Web.
- [Wireframe do Shell Administrativo](09-wireframe-shell-admin.html) - Estrutura inicial de navegação, barra superior, indicadores e área principal do Admin Web.
- [Wireframe Padrão de Tela CRUD](10-wireframe-tela-crud.html) - Modelo inicial de tela para usuários, produtos, categorias, clientes e fornecedores.
- [Wireframe de Relatórios e Conflitos](11-wireframe-relatorios-conflitos.html) - Modelo inicial para telas de vendas, dashboard e conflitos offline com filtros, métricas e detalhe.
- [Usuários, Clientes e Fornecedores](12-apoio-usuarios-clientes-fornecedores.html) - Complemento visual para as telas de apoio administrativo que sustentam acesso, vendas e estoque.

Escopo: mapa de navegação, descrição visual de fluxos, relação com casos de uso e wireframes iniciais. Não inclui pesquisa externa.
